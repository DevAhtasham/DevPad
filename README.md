## Why DevPad?

DevPad is a lightweight, easy-to-use code editor designed specifically for beginners learning HTML, CSS, and JavaScript. Unlike complex IDEs, DevPad offers a simple, intuitive interface where you can:

- Write code and see results instantly
- Learn web development basics without getting overwhelmed
- Practice in a beginner-friendly environment
- Focus on learning without technical setup

![DevPad Interface](assets/screenshot.png)

## Features

### Simple & Beginner-Friendly
- Instant Live Preview: See your changes as you type
- Clean, Distraction-free Interface
- Basic Error Checking: Learn from your mistakes
- Helpful Code Suggestions
- Easy File Management

### Learning-Focused
- Separate HTML, CSS, JS sections for clear learning
- Real-time Output: Perfect for experimenting
- Basic Syntax Highlighting
- Simple Color Themes
- Auto-Save: Never lose your progress

### Perfect for Learning
- No Installation Required
- Works Right in Your Browser
- Share Your Code Easily
- Download Your Projects
- Lightweight and Fast

## Getting Started

### All You Need
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection

### Quick Start
```bash
git clone https://github.com/DevAhtasham/DevPad.git
cd DevPad
start index.html  # or just drag into your browser
```

1. Open DevPad in your browser
2. Choose your theme
3. Start coding in HTML, CSS, or JS
4. See live preview
5. Save your work
