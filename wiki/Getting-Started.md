# Getting Started with DevPad 🚀

Welcome to DevPad! Let's get you started with web development.

## Starting DevPad

1. Download DevPad from the [releases page](../../releases)
2. Unzip the files
3. Open `index.html` in your browser
   - Double-click the file, or
   - Drag it into your browser window

## Understanding the Interface

DevPad has three main panels:

### 1. HTML Panel 📝
- Where you write your webpage structure
- Use tags like `<h1>`, `<p>`, `<div>`
- Example:
  ```html
  <h1>My First Webpage</h1>
  <p>Hello, World!</p>
  ```

### 2. CSS Panel 🎨
- Where you style your webpage
- Make things colorful and organized
- Example:
  ```css
  h1 {
    color: blue;
    text-align: center;
  }
  ```

### 3. JavaScript Panel ⚡
- Where you add interactivity
- Make your webpage respond to actions
- Example:
  ```javascript
  document.querySelector('h1').onclick = function() {
    alert('Hello!');
  }
  ```

### Preview Panel 👀
- Shows how your webpage looks
- Updates automatically as you type
- Test your webpage here

## Basic Controls

- **Save**: Click the 💾 icon or press Ctrl+S
- **Change Theme**: Click the 🎨 icon
- **Reset**: Click the 🔄 icon to start fresh
- **Share**: Click the 📤 icon to share your work
