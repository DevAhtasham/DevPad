# Keyboard Shortcuts ⌨️

Learn these shortcuts to code faster in DevPad!

## Basic Shortcuts

### File Operations
- `Ctrl + S` - Save your work
- `Ctrl + O` - Open a saved project
- `Ctrl + N` - Start new project

### Editor Shortcuts
- `Ctrl + Z` - Undo
- `Ctrl + Y` - Redo
- `Ctrl + A` - Select all
- `Ctrl + C` - Copy
- `Ctrl + V` - Paste
- `Ctrl + X` - Cut

### Code Helpers
- `Tab` - Auto-indent
- `Shift + Tab` - Remove indent
- `Ctrl + /` - Comment/uncomment line
- `Ctrl + Space` - Show code suggestions

### Preview
- `F5` or `Ctrl + R` - Refresh preview
- `Ctrl + B` - Toggle preview panel

## HTML Shortcuts

### Quick Tags
- `!` then `Tab` - Create HTML template
- `.classname` then `Tab` - Create div with class
- `#idname` then `Tab` - Create div with ID

### Common Elements
- `a` then `Tab` - Create link
- `img` then `Tab` - Create image
- `div` then `Tab` - Create div
- `p` then `Tab` - Create paragraph

## Tips

1. Practice these shortcuts regularly
2. Start with the basic ones first
3. Add more as you get comfortable
