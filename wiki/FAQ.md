# Frequently Asked Questions (FAQ) ❓

## General Questions

### What is DevPad?
DevPad is a simple, browser-based code editor designed specifically for beginners learning web development. It lets you write HTML, CSS, and JavaScript with instant preview.

### Do I need to install anything?
No! DevPad works right in your web browser. Just open the `index.html` file and start coding.

### Which browsers support DevPad?
DevPad works in all modern browsers:
- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari

### Is DevPad free?
Yes! DevPad is completely free and open source.

## Usage Questions

### How do I save my work?
Click the save icon (💾) or press `Ctrl + S`. Your work is also auto-saved in your browser.

### Can I share my projects?
Yes! Click the share icon (📤) to get a link or download your project.

### How do I start a new project?
Click the new file icon (📄) or press `Ctrl + N`.

### Why can't I see my changes in the preview?
Make sure:
1. Your code has no errors
2. The preview panel is open
3. Try refreshing with F5

## Technical Questions

### My code isn't working! What should I do?
1. Check for spelling errors
2. Make sure all tags are closed
3. Look for error messages
4. Try the code in [Basic Tutorial](./Basic-Tutorial)

### Can I use external libraries?
Yes! Add them using CDN links in your HTML:
```html
<script src="https://cdn.example.com/library.js"></script>
```
